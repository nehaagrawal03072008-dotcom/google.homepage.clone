# 🌐 Google Homepage Clone

A clean and responsive **Google Homepage Clone** built using HTML and CSS. This project recreates the basic look and layout of Google's homepage and was created as part of my journey into web development.

## 👩‍💻 About the Project

Hi! I'm **Neha Agrawal**, a beginner web developer learning the fundamentals of frontend development.

This project helped me understand how to structure a webpage using HTML and style it using CSS. I recreated Google's familiar homepage layout while practicing alignment, spacing, colors, Flexbox, and responsive design.

## ✨ Features

- 🎨 Google-inspired logo with original colors
- 🔍 Search bar with a search icon
- 📧 Gmail and Images navigation links
- 🔘 Google Search and I'm Feeling Lucky buttons
- 🌍 Multiple language options
- 📱 Responsive layout for mobile screens
- 🦶 Footer with useful navigation links
- ✨ Hover effects on the search bar and buttons

## 🛠️ Technologies Used

- **HTML5** — For webpage structure and content
- **CSS3** — For styling, layout, spacing, and responsiveness
- **Flexbox** — For arranging and aligning elements
- **Media Queries** — For adapting the layout to smaller screens

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/google-homepage-clone.git
   ```

2. Open the project folder:

   ```bash
   cd google-homepage-clone
   ```

3. Open `index.html` in your web browser.

No additional installation or dependencies are required.

*Replace `YOUR-USERNAME` with your GitHub username after enabling GitHub Pages.*
