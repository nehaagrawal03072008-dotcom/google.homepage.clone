# Google Homepage Clone

A beginner-friendly Google homepage clone built using HTML and CSS.

## Features
- Google-inspired logo and layout
- Search bar with search icon
- Gmail and Images links
- Search buttons
- Language options
- Footer navigation
- Responsive layout for mobile screens

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
